# Starlight Swarm Operations Rubric

Score each dimension 0-5.

## 1. Scope Routing

- 5: Cleanly separates Starlight, Arcanea, FrankX, and general prompts.
- 3: Mostly routes correctly but leaves ambiguous edge cases.
- 1: Blurs Starlight operations with Arcanea worldbuilding.

## 2. Executability

- 5: Produces concrete prompt assets, queue tasks, registry updates, or implementation steps.
- 3: Good architecture but weak execution artifacts.
- 1: Only motivational planning.

## 3. Swarm Discipline

- 5: Uses bounded tasks, explicit agents, timeboxes, risks, acceptance criteria, and reports.
- 3: Mentions agents but does not enforce a task contract.
- 1: Performs theatrical swarm language with no operating value.

## 4. Retrieval And Ranking

- 5: Updates taxonomy, registry, rankings, or MCP-ready metadata.
- 3: Saves files but leaves them hard to discover.
- 1: Creates prompts that are disconnected from the library.

## 5. Safety And Evidence

- 5: Protects secrets, dirty worktrees, production risk, and verifies outputs.
- 3: Mentions safety but misses one important boundary.
- 1: Exposes private data or claims unverified execution.

Pass threshold: 22/25 before promotion to trusted Starlight operating prompt.
