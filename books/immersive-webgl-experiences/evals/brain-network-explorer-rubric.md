# Brain Network Explorer Rubric

Score each dimension from 0 to 5.

## 1. Concept Fidelity

- 5: Preserves the WebGL brain, five lobes, 25 concepts, AI/human/bridge cards, and shareable deep links.
- 3: Captures the brain and cards but misses important interaction or content requirements.
- 1: Turns the idea into a generic landing page, diagram, or particle demo.

## 2. Technical Feasibility

- 5: Uses efficient buffers/shaders, deterministic geometry, performance tiers, and repo-aware file paths.
- 3: Uses Three.js but lacks clear fallback or data architecture.
- 1: Proposes infeasible million-node rendering or vague implementation.

## 3. Visual And Motion Quality

- 5: Bio-luminescent brain silhouette, purposeful signal motion, depth, bloom, and reduced-motion route.
- 3: Visually plausible but generic or overdecorated.
- 1: Weak hierarchy, unreadable UI, or motion that blocks exploration.

## 4. Content Quality

- 5: Requires 25 real, typed concepts with Agent/Human/Bridge tabs and related links.
- 3: Includes concept names but not enough card structure.
- 1: Uses placeholder copy or omits editorial content.

## 5. Verification

- 5: Requires build/type/lint gates, desktop/mobile screenshots, canvas nonblank checks, performance checks, and Vercel preview when relevant.
- 3: Mentions testing but lacks visual/canvas-specific proof.
- 1: No meaningful acceptance checks.

Pass threshold: 22/25 for prompt readiness. Below 20 requires rewrite before use.
