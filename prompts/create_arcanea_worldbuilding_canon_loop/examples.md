# Examples

## Example 1 - Faction Lore

Input:

```text
Mission: Create a concise faction compact for a skybound archive guild.
Canon sources: Existing Arcanea lore notes about Luminors, mythic knowledge systems, and creative guardians.
Constraints: Do not overwrite existing guardian names. Keep it usable for cards and concept art.
Target artifact: Faction compact.
Intended use: World bible and prompt-book entry.
```

Expected behavior:

- Routes to Arcanea.
- Names what is confirmed versus invented.
- Produces a compact with role, beliefs, symbols, conflicts, visual anchors, and production hooks.

## Example 2 - Starlight Misroute

Input:

```text
Mission: Create a queue-ready worker task to update prompt registry scripts.
Canon sources: none.
Constraints: preserve dirty files.
Target artifact: swarm task.
Intended use: repo operations.
```

Expected behavior:

- Routes away from Arcanea to Starlight.
- Does not invent lore.
- Produces a short handoff explaining the correct Starlight prompt.
